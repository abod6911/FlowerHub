## 🌟 Overview | نظرة عامة

**FlowerHub** هو نظام متكامل ومصمم خصيصاً لمتاجر وبوتيكات الورد الفاخرة في السعودية والخليج، يجمع بين:
1. **واجهة متجر عميل فاخرة (Customer Storefront)** مع تجربة تسوق فورية خلال ٢٠ دقيقة.
2. **استوديو المنسق الحي (Florist Live Studio & Split View)** للتعديل اللحظي على الأسعار، المخزون، وثيمات العرض.
3. **نظام فواتير وإيصالات حرارية 80mm إلكترونية** متوافقة مع متطلبات التجهيز السريع والطباعة مع باركود التتبع.
4. **طلب مخصص فوري (1-Tap Bespoke WhatsApp Ordering)** مع تشكيل آلي لرسائل التنسيق وتفاصيل كرت الإهداء وتأكيد الصورة قبل الإرسال.

## 💎 Features | المميزات الرئيسية

- 🎨 **Multi-Tenant Design Engine**: تبديل لحظي بين عدة ثيمات فاخرة (Botanical, Velvet Noir, Pearl Minimal, Royal Plum).
- 📱 **Mobile-First & Fully Responsive**: تجربة متوافقة 100% مع الهواتف الذكية والأجهزة اللوحية والشاشات العريضة.
- 🌐 **Full Arabic / English Support**: دعم كامل لاتجاه RTL والخطوط الطباعية الفاخرة (Readex Pro, Cairo, Alexandria, Amiri, Cormorant Garamond).
- 🏷️ **Dynamic Categories & Occasions**: ستوريات دائرية للمناسبات (تخرج، مواليد، يوم ميلاد، حب ورومانسية، جاهز اليوم في الثلاجة).
- 🖨️ **Realistic Thermal POS Printer**: محاكاة واقعية لماكينة طباعة إيصالات المنسق ومطابقة تجهيز الطلبات (Checklist & Ribbons).
- ⚡ **Zero-Friction WhatsApp Checkout**: توليد فوري لتذكرة الطلب بصيغة واضحة للمنسق تشمل خيارات التوصيل، التاريخ، وكرت الإهداء.

## 🛠️ Tech Stack | التقنيات المستخدمة

- **Frontend**: React 19, JSX / TypeScript
- **Styling**: Tailwind CSS v4, Motion (Framer Motion API), Canvas Confetti
- **Icons**: Lucide React, Phosphor Icons
- **Build Tool**: Vite 8 with relative asset resolution for static hosting
- **Code Quality**: Oxlint
- **CI/CD**: GitHub Actions automated workflow for GitHub Pages

## 💻 Local Development | التشغيل المحلي

```bash
# Clone the repository
git clone https://github.com/abod6911/FlowerHub.git
cd FlowerHub

# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Run linting
npm run lint

# Production build
npm run build

# Preview build locally
npm run preview
```
